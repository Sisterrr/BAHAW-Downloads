## Install

1. On your Android phone, open the download link above and download the `.apk` file.
2. Open the downloaded file. If Android requests it, allow your browser or file manager to install this app, then return to the installer.
3. Choose **Install**. For an existing BAHAW installation, install the update without uninstalling to preserve local data.
4. Open BAHAW. Allow notifications and any requested alarm access if you want reminders. Camera/gallery access is used when you choose those features.

Android 8.0 or newer is required. This APK is for Android; it cannot be installed on an iPhone.
